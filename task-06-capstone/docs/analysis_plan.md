# Capstone Analysis Plan (written before modelling)

**Project:** Profit-driven customer churn prediction for a telecom provider
**Author:** Dheena Dhayalan P · RabTech Academy DS Internship, Task 6
**Date fixed:** 2026-11-25. Committed to git before any model was trained.

## 1. Research questions

- **RQ1 (prediction):** How accurately can customer churn be predicted from account, service and
  billing attributes that are available at prediction time?
- **RQ2 (explanation):** Which attributes are most strongly associated with churn, and in which
  direction?
- **RQ3 (decision):** Does a retention campaign targeted with the model make more profit than
  (a) no campaign, (b) contacting every customer, or (c) contacting customers at random?

**Hypotheses**
- H1: the best model beats a logistic-regression baseline on test ROC-AUC.
- H2: contract type, tenure and internet service type are among the strongest churn drivers.
- H3: model-targeted retention makes more profit than all three reference strategies.

## 2. Data

IBM *Telco Customer Churn* sample dataset (7,043 customers × 21 columns),
`data/raw/telco-customer-churn.csv`, SHA-256 `16320c9c…3e91`.
Target: `Churn` (Yes = left within the last month).

## 3. Preparation rules

- `customerID` is dropped (an identifier, not a predictor).
- `TotalCharges` blanks: these are expected for customers with `tenure = 0` and are set to 0.
  Any other blank is an error.
- Engineered features: number of add-on services, an automatic-payment flag, and the ratio of
  average to current monthly charge.
- One-hot encoding for categorical columns and standardisation for numeric columns, both done
  **inside** the cross-validation pipeline so no information leaks from the validation folds.

## 4. Modelling protocol

- **Split:** stratified 80/20 train/test (seed 42). The test set is touched **once**, for final
  evaluation.
- **Models:** majority-class dummy (floor), logistic regression (baseline), random forest and
  histogram gradient boosting.
- **Tuning:** randomised search with stratified 5-fold CV on the training set.
- **Primary metric:** ROC-AUC. **Secondary:** PR-AUC (average precision), Brier score, and F1,
  recall and precision at the chosen threshold. Test ROC-AUC is reported with a 95% bootstrap
  confidence interval (2,000 resamples).
- **Class imbalance:** handled with class weights rather than resampling. Calibration is checked
  with reliability curves.

## 5. Statistical analysis of drivers (RQ2)

- Categorical attributes: χ² test of independence with Cramér's V as the effect size.
- Numeric attributes: Mann-Whitney U test with rank-biserial correlation as the effect size.
- Holm correction across all tests, α = 0.05.
- Model-based importance: permutation importance on the test set, plus logistic-regression
  odds ratios.

## 6. Decision model (RQ3)

For a targeted customer *i* with monthly charge *m<sub>i</sub>*:

| Parameter | Base value | Meaning |
|---|---|---|
| contact cost *c* | $5 | Cost of reaching one customer |
| incentive *d<sub>i</sub>* | 1 × *m<sub>i</sub>* | One free month, given to every contacted customer who accepts |
| success rate *γ* | 30% | Share of contacted would-be churners who stay |
| retained value | 12 × *m<sub>i</sub>* | Twelve months of revenue kept |

Realised profit from contacting *i*:
`y_i · γ · (12·m_i − d_i) − (1 − y_i) · d_i − c`.
Non-churners take the free month, so it is a pure cost for them.

The targeting threshold is chosen on **out-of-fold training predictions** and then applied
unchanged to the test set. A sensitivity analysis varies *γ* (10–50%) and the retention horizon
(6–24 months).
